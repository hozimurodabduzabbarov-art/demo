# PharmaExpress — Frontend (React + Vite)

## Запуск

```
cd frontend
npm install
npm run dev
```
Откроется на http://localhost:3000. Для реальных данных должен быть запущен backend (`../backend`), но приложение также работает автономно на моковых данных из `src/data/products.js`, если backend недоступен — это сделано специально, чтобы демо на защите не сломалось без интернета/БД.

## Что внутри

- **3 языка** (RU / UZ / EN) — `src/i18n/*`, переключаются шапкой сайта.
- **3 валюты** (RUB / UZS / USD) — переключение валюты автоматически следует за языком (RU→₽, UZ→so'm, EN→$), но можно менять и вручную.
- **Каталог** с автопрокручивающейся каруселью баннеров и товаров, как в популярных маркетплейсах.
- **Карточка товара** с выбором варианта упаковки (например, оранжевая/синяя пачка) — при выборе меняется акцентный фон страницы.
- **Корзина** с подсчётом суммы в выбранной валюте.
- **Вход / Регистрация** (мок-JWT, эмулирует backend авторизацию).
- **Предзаказ** дефицитных препаратов, которых нет в наличии.
- **Resale-маркетплейс** («Перепродажа») — пользователь выставляет купленный дорогой препарат на витрину с наценкой не более 30%, аптека удерживает комиссию 10–20%.
- **Admin Panel** (`/admin`) — управление товарами, заказами и модерация лотов перепродажи.
