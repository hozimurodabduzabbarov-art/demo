# PharmaExpress — Telegram Bot

Бот-зеркало приложения: тот же каталог, та же цена/валюта/язык, что и в веб-версии
(запросы идут в тот же backend `../backend`, поэтому данные всегда совпадают).

## Запуск
```
cd bot
cp .env.example .env   # впишите токен от @BotFather и адрес backend
npm install
npm start
```

## Возможности
- `/start` — приветствие, выбор языка (ru/uz/en), кнопка "Открыть приложение" (Telegram Web App → тот же React-фронтенд).
- Если пользователь не зарегистрирован — бот просит номер телефона (через кнопку "Поделиться контактом") и создаёт аккаунт через `/api/auth/signup`, как и в вебе.
- 💊 Каталог — показывает те же товары из `/api/products`, с ценой в валюте, привязанной к языку пользователя.
- 🛒 Корзина — хранится в памяти сессии пользователя, оформление заказа идёт через `/api/orders`, тот же эндпоинт, что использует сайт.
- 📄 Загрузка рецепта — фото пересылается и прикрепляется к заказу.
- ⭐ Предзаказ дефицитных препаратов — `/api/products/:id/preorder`.
- 🔁 Раздел "Перепродажа" — список лотов `/api/resale` и покупка `/api/resale/:id/buy`.

Так как бот и сайт используют один и тот же backend API, каталог, цены и статус
заказов всегда синхронизированы между Telegram и веб-приложением.
