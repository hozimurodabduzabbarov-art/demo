# PharmaExpress — умная онлайн-аптека и сервис доставки

Дипломный проект: E-commerce / HealthTech сервис. Пользователь ищет лекарства,
оформляет доставку, делает предзаказ дефицитных препаратов, может перепродать
неиспользованное лекарство другим пользователям через встроенный маркетплейс.

## Структура репозитория

```
pharmaexpress/
├── backend/         Node.js + Express + MongoDB REST API
├── frontend/        React (Vite) — веб-приложение, 3 языка / 3 валюты
├── bot/     Telegram-бот, использует тот же backend API, что и сайт
└── README.md         этот файл
```

## Быстрый старт (для защиты проекта)

> ⚠️ **Сначала распакуйте архив!** Если вы скачали `pharmaexpress.zip`, сначала
> нажмите правой кнопкой → «Извлечь всё» (Extract All), и только потом
> открывайте появившуюся папку `pharmaexpress` в VS Code — .zip нельзя
> редактировать или запускать напрямую, редактор поэтому и показывает
> «binary / unsupported encoding».


```bash
# 1) Backend
cd backend
cp .env.example .env
npm install
npm run seed      # заполнить БД тестовыми лекарствами
npm run dev        # http://localhost:5000

# 2) Frontend (в новом терминале)
cd frontend
npm install
npm run dev         # http://localhost:3000

# 3) Telegram-бот (опционально, в новом терминале)
cd bot
cp .env.example .env   # впишите токен от @BotFather
npm install
npm start
```

> Frontend умеет работать даже без запущенного backend — на моковых данных
> из `frontend/src/data/products.js`. Это подстраховка на случай, если на
> защите не будет интернета/MongoDB под рукой.

## Что реализовано (чек-лист для комиссии)

- [x] **Регистрация / вход** — экран Login/Signup, JWT-авторизация на backend (`auth/Login.js`, `auth/Signup.js`), сессия на фронте.
- [x] **3 языка**: русский, узбекский (o'zbekcha), английский — переключаются шапкой сайта.
- [x] **3 валюты**: при переключении языка валюта меняется автоматически (RU → ₽, UZ → so'm, EN → $), с реалистичным курсом относительно узбекского сума.
- [x] **Каталог** с категориями, поиском, автоматически прокручивающейся каруселью баннеров — как в популярных маркетплейсах.
- [x] **Карточка товара** с вариантами упаковки/цвета (например оранжевая/синяя пачка) — при выборе меняется акцентный фон карточки.
- [x] **Корзина** с пересчётом суммы в выбранной валюте, оформление заказа.
- [x] **Загрузка рецепта** для рецептурных препаратов.
- [x] **Предзаказ дефицитных препаратов**, которых нет в наличии — аптека бронирует у поставщика.
- [x] **Resale-маркетплейс** — купил дорогой/редкий препарат, не понадобился → выставил на перепродажу другим пользователям с наценкой не более 30%; аптека автоматически удерживает комиссию 10–20% с каждой сделки, остальное зачисляется продавцу.
- [x] **Admin Panel** (`/admin` на фронте, `/api/admin/*` на бэке) — управление товарами, просмотр всех заказов, модерация лотов перепродажи.
- [x] **Telegram-бот**, использующий тот же backend API, что и сайт — каталог, цены и язык всегда совпадают с веб-версией.
- [x] Backend-структура строго по требуемому шаблону: `api / auth / controllers / middlewares / models / routes`.
- [x] **Тёмная тема** — переключатель 🌙/☀️ в шапке, сохраняется между визитами (`ThemeContext.jsx`).
- [x] **Живое отслеживание курьера** (как в Яндекс Еде) — статусы «Принят → Собран → В пути → Почти на месте → Доставлено», ETA в минутах, которое пересчитывается в реальном времени с учётом смоделированного трафика и светофоров, анимированный маршрут на карте (`pages/CourierTracking.jsx`, открывается автоматически после оформления заказа).
- [x] **Виджет поддержки 24/7** — плавающая кнопка чата с быстрыми ответами на частые вопросы (`components/SupportWidget.jsx`).
- [x] **Актуальные цены** — пересчитаны на основе реальных розничных цен в аптеках РФ и официального курса ЦБ Узбекистана (проверено 25.08.2026: 1 USD = 11 818,07 UZS, 1 RUB = 141,69 UZS).

## О фото упаковок лекарств

Вместо чужих/стоковых фотографий (которые могут быть защищены авторским правом
конкретных фарм-брендов) используются векторные SVG-иллюстрации коробочек
(`components/MedBox.jsx`) — это надёжнее для демонстрации на защите (не зависит
от интернета и не нарушает копирайт) и при этом красиво меняет цвет/фон при
выборе другого варианта упаковки. Если для финальной версии нужны настоящие
фото — просто добавьте свои файлы в `frontend/public/products/` и замените
`<MedBox .../>` на `<img src="/products/ваш-файл.jpg" />` в `ProductCard.jsx`
и `ProductDetail.jsx`.

## Демо-доступ в админку

При входе под номером телефона **+998900000000** (любой пароль) аккаунт
получает роль `admin` — так можно сразу показать комиссии `/admin`.
